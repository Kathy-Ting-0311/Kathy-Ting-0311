# Variable

## Creating Variable
```Python
x = 5  # Assign x a number value
y = "Amy" # assign y a string value
```

## Casting 
> If you want to set specify data type of a value

``` python
x = str(3) # which will be '3'
y = int(3) # which will be 3
z = float(3) # which will be 3.0
```

## Get the Type
> Sometime maybe you want to check the variable type, Here have a function can help you better get the type of variable

```python
x = 5
print(type(x))
```
